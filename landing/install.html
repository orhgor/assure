Install

The workbench runs on this computer. This website is not the app. There is no public download file yet. Updated 1 September 2026.

From source

On the Assure source tree on this machine:

./scripts/install.sh then assure --web

Windows: scripts\install.ps1 then assure --web.

pip install prompt-matrix is not on PyPI yet. Do not clone orhgor/assure for the app. That GitHub repo is the webpage.

Desktop builds

These scripts produce an app on this computer. They are not a public store download.

macOS: ./scripts/build-desktop.sh then double-click dist/Assure.app.

Windows: scripts\build-desktop.ps1.

Linux: see the same scripts folder in the source tree.

The app opens

Your browser should open. First run: paste a provider key, then write a question. There is no password on this computer unless you set one. If the window does not open, go to http://127.0.0.1:8765.
