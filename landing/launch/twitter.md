# X thread

Why I built Assure for people who cannot paste the brief into a random chat.

1/
I kept pasting the same client question into ChatGPT, then Claude, then a third tab. Sunday night was the merge.

2/
The merge was me. There was no overlap view. A confident percent still slipped in if I got tired.

3/
The other problem was quieter. A model will invent a paper. You only catch it if you already know the literature. That is a bad filter.

4/
I wanted three things on this computer: pick who answers, see where two models agree, drop claims that were not in the file I attached.

5/
That is Assure. The compiler is PEM. You run `assure --web` and open http://127.0.0.1:8765.

6/
Copy stays here. You paste the compiled prompt yourself.

Send goes only to Gemini, DeepSeek, Claude, Kimi, or a runner closed to the internet. You chose that provider. There is no second Assure cloud holding the brief.

7/
Closed to the internet means the question does not leave this machine. Open to the internet means it does. Say it that way. "Your data never leaves" is a lie if Send is on.

8/
Free is 10 Sends a day. Pro is $5 a month. Team in this repo is unlimited Sends on this machine, not a shared workspace.

9/
If you are a consultant, researcher, or analyst, and you already pay for a model, you do not need a new chatbot. You need a checked answer.

10/
Repo install, then ask. Example on Compose: compare AWS vs GCP for a healthcare client. Do not invent prices.
