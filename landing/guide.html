Assure Quickstart & Verification Guide

Configure your API keys in 60 seconds, run document grounding checks, and interpret NLI trust signals.

Getting Your API Keys (BYOK in 60 Seconds)

Assure never bills you for tokens. You bring your own API keys. They are stored strictly in your browser's localStorage and never written to an Assure database.

Google Gemini Setup

  1. Open Google AI Studio (aistudio.google.com).
  2. Click Get API key → Create API key.

Gemini 1.5 Flash includes a free tier with zero upfront charges.

Anthropic Claude Setup

  1. Open console.anthropic.com.
  2. Navigate to API Keys → Create Key.

Understanding the Trust Signals (Green vs. Yellow)

  • 🟢 Green: Directly Entailed. The claim is explicitly supported and verified by your source text.
  • 🟡 Yellow: Inferred / General Knowledge. The claim may be true in reality, but it cannot be verified from your uploaded document alone.
  • Model Attribution: Pills reflect strictly the models that returned HTTP 200 during that run.

Confidentiality & Privacy Shield

Zero document retention

Uploaded files are processed in memory for the audit. Assure does not store your documents on our servers.

Client-side key storage

API keys live in browser localStorage only — never in our database.

In-memory NLI scoring

Sentence-level checks run during your session without persisting source text to the cloud.

Local SQLite history

Run history stays on your machine in a local SQLite database you control.
