Quick start

The workbench runs on this computer. Install from the product source. The public GitHub repo is the site only.

  1. Install

    ./scripts/install.sh

    Python 3.10 or newer. On Windows, scripts\install.ps1.

  2. Run

    assure --web

    Open http://127.0.0.1:8765. HTTP Basic is admin / changeme until you change it. First run opens Connect if no provider is pasted yet.

  3. Ask

    Write a question, or click an example on Compose. Send and get my answer is the default.

pip install prompt-matrix is not on PyPI yet. Do not clone orhgor/assure for the app. That branch is the webpage.
