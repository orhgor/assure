CrossSure then runs the Z3 check: a labeled number is decided by Z3, not by the language model; an unlabeled sentence is turned into a numeric comparison by the language model, and Z3 decides whether it holds. Red-Hat review, if someone runs it, tries to find what is wrong in that draft. The review screen shows a Z3 contradiction as export blocked. A person accepts or rejects each finding. {{ strings.get('about.checks.title', 'How Assure checks a case file') }}

{{ strings.get('about.checks.1', 'ParSure reads every document and keeps each figure tied to its source page. A language model then writes the draft (DraftSure). CrossSure runs after that draft exists. Z3 decides whether the draft\'s figures and the values locked from the source can all be true at the same time. For a labeled number, the language model does not make that call. For a sentence with no label, the language model turns it into a numeric comparison, and Z3 decides whether it holds. When a file is first read, Z3 can also flag figures in that file that contradict each other.') }}

{{ strings.get('about.checks.2', 'Red-Hat review is separate, and it runs only when someone asks for it. It does not decide the numeric conflict. The review screen shows a Z3 contradiction as export blocked. A person accepts or rejects each finding. The file can still be downloaded.') }}
