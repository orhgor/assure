{{ strings.get('home.faq.2.q', 'What documents can it check?') }}

{{ strings.get('home.faq.4.q', 'Who makes the decision?') }}
{{ strings.get('home.faq.4.a', 'A person. The layer shows each finding with its source page, and your reviewer approves or rejects it.') }}
{{ strings.get('home.faq.5.q', 'What is the formal consistency checker, and why does Assure use one?') }}
{{ strings.get('home.faq.5.a', 'The formal consistency checker is software that tests whether a set of figures and conditions can all be true at the same time. It receives the draft\'s figures and the values locked from the source. For a labeled number, the formal consistency checker makes the decision and the language model does not. For a sentence with no label, the language model turns it into a numeric comparison, and a formal consistency checker tests whether it holds.') }}
{{ strings.get('home.faq.6.q', 'How is the formal consistency check different from a language model reviewing the document?') }}
{{ strings.get('home.faq.6.a', 'A language model writes text and can propose a numeric comparison. It does not decide whether a labeled figure conflicts with the value locked from the source. the formal consistency checker makes that decision. Red-Hat review is a different pass: a language model tries to find what is wrong in the draft, and a person decides what to do with each finding.') }}
{{ strings.get('home.faq.7.q', 'What does the Red-Hat review check?') }}
{{ strings.get('home.faq.7.a', 'Red-Hat review runs only when someone asks for it, on the draft the draft has already written. A language model looks for a mismatch with the attached source sentence, an overstatement, a missing clause, or a figure that needs a citation.') }}
{{ strings.get('home.faq.8.q', 'Does a failed check stop the file from downloading?') }}
{{ strings.get('home.faq.8.a', 'The review screen shows the contradiction as export blocked. Red-Hat review findings are left for a person to accept or reject. The file can still be downloaded.') }}
