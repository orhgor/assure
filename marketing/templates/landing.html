{{ strings.get('home.faq.2.q', 'What documents can it check?') }}
{{ strings.get('home.faq.2.a', 'Scans, PDFs, forms, contracts, invoices, receipts and certificates, including handwritten and scanned reports, alongside your SAP exports.') }}
{{ strings.get('home.faq.3.q', 'Where does it run?') }}
{{ strings.get('home.faq.3.a', 'In your own AWS account or on-premises. You choose where the models run, including your own GPU servers.') }}
{{ strings.get('home.faq.4.q', 'Who makes the decision?') }}
{{ strings.get('home.faq.4.a', 'A person. The layer shows each finding with its source page, and your reviewer approves or rejects it.') }}
{{ strings.get('home.faq.5.q', 'What is Z3, and why does Assure use it?') }}
{{ strings.get('home.faq.5.a', 'Z3 is an SMT solver, satisfiability modulo theories: software that decides whether a set of figures and conditions can all be true at the same time. CrossSure gives it the draft\'s figures and the values locked from the source. For a labeled number, Z3 makes the decision and the language model does not. For a sentence with no label, the language model turns it into a numeric comparison, and Z3 decides whether it holds.') }}
{{ strings.get('home.faq.6.q', 'How is the Z3 check different from a language model reviewing the document?') }}
{{ strings.get('home.faq.6.a', 'A language model writes text and can propose a numeric comparison. It does not decide whether a labeled figure conflicts with the value locked from the source. Z3 makes that decision. Red-Hat review is a different pass: a language model tries to find what is wrong in the draft, and a person decides what to do with each finding.') }}
{{ strings.get('home.faq.7.q', 'What does the Red-Hat review check?') }}
{{ strings.get('home.faq.7.a', 'Red-Hat review runs only when someone asks for it, on the draft DraftSure has already written. A language model looks for a mismatch with the attached source sentence, an overstatement, a missing clause, or a figure that needs a citation.') }}

{{ strings.get('home.faq.8.a', 'The review screen shows a Z3 contradiction as export blocked. Red-Hat review findings are left for a person to accept or reject. The file can still be downloaded.') }}
