{{ strings.get('faq.title', 'Questions') }}

{{ strings.get('faq.q1', 'What is AssureProof?') }}

{{ strings.get('faq.a1', 'AssureProof reads your contracts, invoices, claims and bids together and marks every figure that does not match across them, with both source pages open. A person reviews each flag and decides. It runs in your own AWS account or on your own servers, including air-gapped networks.') }}

{{ strings.get('faq.q2', 'What is Z3?') }}

{{ strings.get('faq.a2', 'Z3 is a formal logic solver (SMT solver) that mathematically proves whether a set of figures and constraints can all be true at the same time. It gives a deterministic yes/no answer — no probability, no hallucination.') }}

{{ strings.get('faq.q3', 'What does “deterministic” mean here?') }}

{{ strings.get('faq.a3', 'The same inputs always produce the same output. There is no randomness, no temperature setting, and no model drift. If the figures conflict today, they will conflict tomorrow.') }}

{{ strings.get('faq.q4', 'What is Red-Hat review?') }}

{{ strings.get('faq.a4', 'An optional, separate adversarial pass where a language model tries to find flaws in the draft — missing citations, overstated claims, or numbers that do not trace back to a source page. It runs only when requested.') }}

{{ strings.get('faq.q5', 'Does a contradiction block export?') }}

{{ strings.get('faq.a5', 'Yes. Export is automatically locked while any contradiction is unresolved. A person (or an authorized agent) must accept or reject each finding before the file can be downloaded. The file stays downloadable the entire time — you just cannot export a conflicted version.') }}

{{ strings.get('faq.q6', 'Where does AssureProof run?') }}

{{ strings.get('faq.a6', 'In your own AWS account (using Amazon Bedrock), on a private GPU, or on your own on-premises servers — including air-gapped networks. You choose the deployment model; documents never leave your boundary unless you connect an external endpoint yourself.') }}
