{{ strings.get('faq.title', 'Questions') }}

{{ strings.get('faq.1.q', 'What is AssureProof?') }}

{{ strings.get('faq.1.a', 'AssureProof reads your PDFs and scans. When you ask for a draft, it writes one from those files, checks the draft against what it read from your files, and shows the figures and statements that don\'t match what the files say. A person reviews each flag and decides. It runs in your own AWS account or on your own servers.') }}

{{ strings.get('faq.2.q', 'How is AssureProof different from extraction tools and RAG tools?') }}

{{ strings.get('faq.2.a', 'Extraction tools read data out of a file and return fields. RAG tools answer questions and cite sources. AssureProof writes a draft from your files and then shows where that draft conflicts with them, so a reviewer sees the mismatches before the draft is approved, paid or sent.') }}

{{ strings.get('faq.3.q', 'What is Z3?') }}

{{ strings.get('faq.3.a', 'Z3 is software that decides whether a set of figures can all be true at the same time. AssureProof uses it on the figures and dates in a draft. A language model writes the relation, such as "the invoice total is at most the contract cap", and Z3 checks it against the values read from your files. Each check reports pass, fail, skipped, timeout or error.') }}

{{ strings.get('faq.4.q', 'What does "deterministic" mean here?') }}

{{ strings.get('faq.4.a', 'It means the figure check gives the same answer each time for the same figures and the same relation. Reading the files and writing the draft are done by language models, and a model writes the relation that is checked, so those steps can vary. That is why a person reviews each flag before anything is approved.') }}

{{ strings.get('faq.5.q', 'Does AssureProof check every statement in the draft?') }}

{{ strings.get('faq.5.a', 'No. Z3 checks figures and dates where a relation can be written. Statements are judged by a language-model support check against the cited source. Each draft claim must cite a source, page and field, or a quote, and a citation that does not resolve fails the claim. A skipped or errored check is never reported as a pass.') }}

{{ strings.get('faq.6.q', 'What is Red-Hat review?') }}

{{ strings.get('faq.6.a', 'Red-Hat review is a second language-model pass that runs on every draft and on each document\'s fields. It looks for weak claims, such as an overstatement or a figure that needs a citation, and lists them with reasons. It does not block anything. A person decides what to do with each one.') }}

{{ strings.get('faq.7.q', 'Does a contradiction block export?') }}

{{ strings.get('faq.7.a', 'No. AssureProof marks the contradiction and a person decides. A reviewer can accept a value over a Z3 or Red-Hat review objection, and that decision is recorded with who made it and when. You can export fields as CSV or JSON, with the JSON signed so it can be verified, and drafts as JSON or PDF.') }}

{{ strings.get('faq.8.q', 'What files can AssureProof read?') }}

{{ strings.get('faq.8.a', 'ParSure reads PDFs, including scans, and PNG, JPEG, TIFF and BMP images, up to 25 MB and 200 pages per file by default. Handwritten and illegible values are flagged, and illegible values are not guessed. CrossSure reads spreadsheets in XLSX, XLSM, XLS, CSV and TXT formats without a model.') }}

{{ strings.get('faq.9.q', 'Where does AssureProof run?') }}

{{ strings.get('faq.9.a', 'Runs in your own AWS account or on your own servers, including air-gapped networks; model calls go to your Amazon Bedrock account (or a self-hosted model on a GPU). Files are stored on your own disk or in your S3 bucket. With a self-hosted model, document text stays inside your environment. Data is encrypted in transit and at rest.') }}

{{ strings.get('faq.10.a', 'Yes. Bring a real document set for one workflow. We agree a fixed scope in writing, run it with your team and walk you through the findings. Use the contact form or write to sales@assureproof.com.') }}
