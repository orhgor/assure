{{ strings.get('faq.q5', 'Does a contradiction block export?') }}

{{ strings.get('faq.a5', 'No. AssureProof marks the contradiction and a person decides. A reviewer can accept a value over a formal logic check or a second adversarial review, and that decision is recorded with who made it and when. {{ strings.get('faq.q2', 'What is the formal logic check?') }}

{{ strings.get('faq.a2', 'A formal logic check proves whether a set of figures and constraints can all be true at the same time. The figure check gives the same answer each time for the same figures and the same rules.') }}

{{ strings.get('faq.q3', 'Why does the figure check give the same answer every time?') }}

{{ strings.get('faq.a3', 'The figure check gives the same answer each time for the same figures and the same rules. Reading the documents and drafting use language models, so every figure keeps its source page for a person to confirm. If the figures conflict today, they will conflict tomorrow.') }}

{{ strings.get('faq.q4', 'What is the second adversarial review?') }}

{{ strings.get('faq.a4', 'A separate adversarial pass in which a language model tries to find flaws in the draft — missing citations, overstated claims, or numbers that do not trace back to a source page. The second adversarial review is configured per customer deployment: it can run on every draft or only when a reviewer requests it. It never blocks a decision or an export.') }}
