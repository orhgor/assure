{{ strings.get('faq.q1', 'What is AssureProof?') }}

{{ strings.get('faq.a1', 'AssureProof reads your contracts, invoices, claims and bids together and marks every figure that does not match across them, with both source pages open. {{ strings.get('faq.q6', 'Where does AssureProof run?') }}

{{ strings.get('faq.a6', 'In your own AWS account (using Amazon Bedrock), on a private GPU, or on your own on-premises servers — including air-gapped networks. You choose the deployment model; documents never leave your boundary unless you connect an external endpoint yourself.') }}

{{ strings.get('faq.dlp.q', 'Do you train models on our documents?') }}

{{ strings.get('faq.dlp.a', 'No. We do not use your documents to train models. With a self-hosted model, document text does not leave your network. Data is encrypted in transit with TLS 1.3 and at rest with AES-256, and you can use your own encryption keys.') }}

{{ strings.get('faq.q5', 'Does a contradiction block export?') }}

{{ strings.get('faq.a5', 'No. AssureProof marks the contradiction and a person decides. A reviewer can accept a value over a Z3 or Red-Hat review objection, and that decision is recorded with who made it and when. You can export fields as CSV or JSON, with the JSON signed so it can be verified, and drafts as JSON or PDF.') }}

{{ strings.get('faq.q2', 'What is Z3?') }}

{{ strings.get('faq.a2', 'Z3 is a formal logic solver (SMT solver) that mathematically proves whether a set of figures and constraints can all be true at the same time. The figure check itself is deterministic: the same figures and rules always give the same answer.') }}

{{ strings.get('faq.q3', 'What does “deterministic” mean here?') }}

{{ strings.get('faq.a3', 'The figure check itself is deterministic: the same figures and rules always give the same answer. Reading the documents and drafting use language models, so every figure keeps its source page for a person to confirm. If the figures conflict today, they will conflict tomorrow.') }}

{{ strings.get('faq.q4', 'What is Red-Hat review?') }}

{{ strings.get('faq.a4', 'A separate adversarial pass in which a language model tries to find flaws in the draft — missing citations, overstated claims, or numbers that do not trace back to a source page. The Red-Hat review is configured per customer deployment: it can run on every draft or only when a reviewer requests it. It never blocks a decision or an export.') }}
