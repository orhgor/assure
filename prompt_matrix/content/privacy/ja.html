Assure AI（“当社”、“私たち”、または“弊社”）は、お客様のプライバシー保護に努めています。本プライバシーポリシーは、当社のプラットフォームおよびサービスをご利用いただく際に、当社がどのように情報を収集、利用、保護するかを説明します。

1. 収集・保存するデータ

a. クラウド（サーバー）に保存されるデータ

サービス提供のため、当社の安全なサーバー（AWS EC2）に以下のデータを保存します：

  • アカウントデータ： メールアドレス、サブスクリプション階層、Stripe 顧客 ID。
  • 質問とプロンプト： コマンドバーまたはコンパイル画面に入力するテキスト（データベースのプロジェクトおよび実行ログに保存）。
  • アップロードされたソースファイル： PDF、画像、JSON、YAML その他のアップロード文書（substrate_vault テーブルに保存）。
  • コンパイル済みドラフト： JDF AST、検証ログ、ロックハッシュ（jdf_revisions テーブルに保存）。
  • 監査ログ： エンタープライズコンプライアンス用の活動およびリクエストログ（user_activity_log および audit_log に保存）。
  • ウェイトリスト登録： メール、会社名、ワークフロータイプ（ウェイトリストに参加した場合）。

当社はお客様のデータをモデル訓練に使用しません。当社は広告またはマーケティング目的で第三者にデータを販売または共有しません。

b. お客様の端末にローカル保存されるデータ

以下のデータはお客様のコンピューター上に留まり、当社のサーバーには送信されません：

  • 接続済みプロバイダーの API キー（Claude、Gemini、DeepSeek、Kimi など）。
  • Workbench UI の状態および設定（レイアウト設定、テーマ設定など）。

c. 第三者 AI プロバイダー（“送信”時）

接続済みプロバイダーにプロンプトを送信することを選択した場合：

  • お客様の質問および添付ファイルは、セッションから選択したプロバイダーへ直接送信されます。
  • プロバイダー固有の利用規約およびプライバシーポリシーが適用されます。利用前に確認し、同意する必要があります。
  • Assure は、標準的なワークスペース履歴の一部としてプロジェクトファイルおよびドラフトに永続保存される範囲を超えて、第三者 API の生レスポンスを独自に記録または保持しません。

d. “インターネットに閉じた”モード

“インターネットに閉じた”が選択されている場合：

  • お客様のデータは外部プロバイダーに送信されません。
  • 処理（Z3 検証および groundrails を含む）はAssure の安全なサーバー上で実行されます—ローカルマシン上ではありません。
  • お客様のデータは、セクション 1a で説明するとおり、引き続き Assure のサーバーに保存されます。
