Assure AI（“我们”、“我们的”或“我方”）致力于保护您的隐私。本隐私政策说明当您使用我们的平台和服务时，我们如何收集、使用和保护您的信息。

1. 我们收集和存储的数据

a. 存储在云端的（服务器）数据

为提供服务，我们在安全服务器（AWS EC2）上存储以下数据：

  • 账户数据：电子邮件地址、订阅层级和 Stripe 客户 ID。
  • 问题和提示词：您在命令栏或编译界面中输入的文本（存储在数据库项目和运行日志中）。
  • 上传的源文件：您上传的 PDF、图片、JSON、YAML 及其他文档（存储在 substrate_vault 表中）。
  • 编译草稿：JDF AST、验证日志和锁定哈希（存储在 jdf_revisions 表中）。
  • 审计日志：用于企业合规的活动和请求日志（存储在 user_activity_log 和 audit_log 中）。
  • 候补名单提交：电子邮件、公司名称和工作流类型（如您加入候补名单）。

我们不会使用您的数据训练我们的模型。我们不会出于广告或营销目的向第三方出售或共享您的数据。

b. 本地存储在您设备上的数据

以下数据保留在您的计算机上，绝不会传输至我们的服务器：

  • 已连接提供商的 API 密钥（Claude、Gemini、DeepSeek、Kimi 等）。
  • Workbench 界面状态和偏好设置（例如布局设置、主题偏好）。

c. 第三方 AI 提供商（当您“发送”时）

当您选择向已连接的提供商发送提示词时：

  • 您的问题及任何附加文件会直接从您的会话传输至您选择的提供商。
  • 适用该提供商自身的条款和隐私政策。使用前您须审阅并接受。
  • Assure 不会独立记录或保留原始第三方 API 响应，超出作为标准工作区历史一部分持久保存至项目文件和草稿的范围。

d. “对互联网关闭”模式

选择“对互联网关闭”时：

  • 您的数据不会发送至任何外部提供商。
  • 处理（包括 Z3 验证和 groundrails）在 Assure 的安全服务器上运行—而非您的本地机器。
  • 您的数据仍按第 1a 节所述存储在 Assure 的服务器上。
