# v1.5 Production Promotion Runbook (Option A — Enhanced)

**Target:** `main` → production @ https://getassureai.com

## 1. Pre-flight

### 1.1 Downtime / active users

```bash
curl -s https://getassureai.com/health | python3 -m json.tool
```

Confirm `status: healthy`. Pilot scale — brief deploy window (~2 min) is acceptable.

### 1.2 Backup database (production EC2)

**Path on EC2:** `/home/ubuntu/assure/data/history.sqlite` (see `docker-compose.prod.yml` → `DATABASE_PATH: /app/data/history.sqlite`)

```bash
# On production EC2 (SSM session or SSH as ubuntu)
cd /home/ubuntu/assure
STAMP=$(date +%Y%m%d_%H%M%S)
cp data/history.sqlite "data/backups/history.sqlite.${STAMP}"
sqlite3 data/history.sqlite ".backup 'data/backups/history.sqlite.${STAMP}.db'"
ls -lh data/backups/history.sqlite.${STAMP}*
```

Record **`STAMP`** for rollback (example: `20260908_174500`).

Optional R2 backup:

```bash
sudo bash scripts/aws/backup-sqlite.sh
```

## 2. Rollback procedure (run if migration or verification fails)

**When to rollback:** v17 migration error, `/health` not OK within 5 min, lock gate fails, or audit export broken.

```bash
# On production EC2
cd /home/ubuntu/assure
export STAMP=<backup_timestamp_from_step_1.2>

docker compose -f docker-compose.yml -f docker-compose.prod.yml down

cp "data/backups/history.sqlite.${STAMP}" data/history.sqlite
# or: cp "data/backups/history.sqlite.${STAMP}.db" data/history.sqlite

git fetch origin
git checkout -B main v1.4.0
export ASSURE_IMAGE_TAG=$(git rev-parse HEAD)
export GHCR_TOKEN=<deploy_token>
bash scripts/aws/redeploy-app.sh --tag "$ASSURE_IMAGE_TAG"

curl -sf http://127.0.0.1:8765/health | python3 -m json.tool
```

Verify `ui.css_version` returns `assure-96` and `build_sha` matches v1.4.0 commit.

## 3. Promote (GitHub)

```bash
git fetch origin staging main
git checkout main
git pull origin main
git merge origin/staging --no-ff -m "chore: promote v1.5 to production"
git push origin main
git tag -a v1.5.0 -m "v1.5 — Enterprise Compliance (drift, sign-off, locking, audit bundle)"
git push origin v1.5.0
```

This triggers **Deploy to Production** (GHCR build + SSM redeploy). Migration v17 runs on app startup via `init_db()`.

## 5. Verification gate

### 5.1 Health

```bash
curl -s https://getassureai.com/health | python3 -m json.tool
```

Expected:

- `ok: true`
- `ui.css_version: assure-97`
- `ui.js_version: assure-97`
- `build_sha` = merge commit on `main`

### 5.2 Lock + 409 (authenticated session or local gate tests)

```bash
uv run pytest tests/test_document_lock.py tests/test_drift_endpoint.py -v
```

Production API (with valid session):

1. `POST /api/projects/{id}/lock` → 200
2. `PUT /api/projects/{id}/jdf` → **409** `Document is locked`
3. New project (unlocked) → `PUT /jdf` → **200**

### 5.3 Post-deploy smoke

```bash
# Health + export format list
curl -sI "https://getassureai.com/api/projects/default/export?format=audit-pdf" | head -5
uv run pytest tests/test_production_v15_smoke.py -v
```
